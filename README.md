# Internship Projects Codebase

This repository contains two separate projects, each maintained in its own branch.

---

## 🔹 Project 1: AI/ML-Based Software Licensing Management System
This project focuses on building an intelligent system to manage and optimize software licenses using AI and machine learning techniques. It aims to:
- Improve license utilization  
- Reduce software costs  
- Automate tracking and compliance  

---

## 🔹 Project 2: License Analytics Chatbot System (OpenSearch)
This project is a chatbot-based analytics system powered by OpenSearch. It allows users to:
- Query license-related data using natural language  
- Generate insights and reports  
- Analyze usage trends efficiently  

---

## 📌 Repository Structure
Each project is developed in a separate branch:

- `ai-ml-licensing-system`
- `license-analytics-chatbot`
